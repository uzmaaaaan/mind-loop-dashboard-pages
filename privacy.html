Privacy policy: Mind Loop Dashboard

Last updated: 20 November 2026.

Who uses it. Mind Loop Dashboard is used only by its owner, on the owner's own computer, to manage the owner's own YouTube channels.

What it accesses. After the owner signs in with Google, the app reads the owner's YouTube channel data (videos, titles, schedules, view counts and analytics) through the YouTube Data API and YouTube Analytics API, and, where the owner allows it, edits titles, descriptions, tags and publish times of the owner's own videos.

What it stores. Sign-in tokens and the data above are stored only in files on the owner's own computer. Nothing is uploaded to any server run by the developer, sold, shared with anyone, or used for advertising.

Google API Services. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. The owner can remove the app's access at any time at myaccount.google.com/permissions and delete the local files.
